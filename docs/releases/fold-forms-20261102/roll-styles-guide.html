Roll styles and folding

Roll style और folding

How to set up a folded roll, a tube roll or a roll with a flap, so the folding step, the floor and costing all read the same numbers.

Folded roll, tube roll या flap वाला roll कैसे बनाएँ, ताकि folding step, floor और costing सब एक ही नंबर पढ़ें।

One rule for every fold

हर fold का एक ही नियम

open web =2 × W+flap+seal+trim

W is the roll width you sell or stock (folded or lay-flat). Flap is how much longer one wall is (0 for a plain fold). Seal is the film the edge seal uses when the machine also seals into a tube. Trim is edge trim cut at the folder; it is scrap and is not costed as film.

W = roll की width जो बेचते या रखते हैं (folded या lay-flat)। Flap = एक दीवार कितनी लंबी है (सीधे fold में 0)। Seal = tube बनाते समय edge seal में लगी film। Trim = folder पर कटा किनारा; यह scrap है, film की कीमत में नहीं गिना जाता।

Example: Folded 300 mm with a 20 mm flap and 10 mm trim needs 2 × 300 + 20 + 10 = 630 mm of open web.

उदाहरण: Folded 300 mm, flap 20 mm, trim 10 mm के लिए 2 × 300 + 20 + 10 = 630 mm open web चाहिए।

Making a new roll size

नया roll size बनाना

  1. Open Master → Product masters, open the roll product, go to Sizes and add a size.

    Master → Product masters खोलें, roll product खोलें, Sizes में नया size जोड़ें।

  2. Type Roll width (mm). For a folded or tube roll this is the folded / lay-flat width W, not the open width.

    Roll width (mm) भरें। Folded या tube roll में यह folded / lay-flat width W है, open width नहीं।

  3. Pick a Roll style (fastest), or leave it on None and pick Roll form: FLAT, FOLDED or TUBING.

    Roll style चुनें (सबसे आसान), या None रखकर Roll form चुनें: FLAT, FOLDED या TUBING।

  4. For FOLDED or TUBING fill Flap (mm), Seal (mm) and Fold trim (mm). The grey note below shows the open web the folder needs. Check it matches the shop floor.

    FOLDED या TUBING में Flap (mm), Seal (mm) और Fold trim (mm) भरें। नीचे की grey line बताती है folder को कितना open web चाहिए। Floor से मिलान करें।

  5. Save. Orders that pick this size now carry the form and fold; you add nothing on the sales order.

    Save करें। इस size वाले order में form और fold अपने आप आता है; sales order में कुछ अलग नहीं भरना।

Picking Roll form by hand removes the roll style from that size (the style would set the form back). A size can keep a style and still type its own flap.

Roll form हाथ से चुनने पर उस size से roll style हट जाता है। Size style रखकर भी अपना flap भर सकता है।

Roll styles and pouch styles: one page, two tabs

Roll style और pouch style: एक page, दो tab

Master → Pouch & roll styles. The Pouch styles tab works as before: a formula turns the pouch size into the stock width. The Roll styles tab holds named forms with their fold. New roll style opens a short form: name, Default stock form, then Flap, Seal, Fold trim. Save and approve; then sizes can use it.

Master → Pouch & roll styles। Pouch styles tab पहले जैसा: formula pouch size से stock width बनाता है। Roll styles tab में नाम वाले form और उनका fold। New roll style में नाम, Default stock form, फिर Flap, Seal, Fold trim भरें। Save और approve करें; फिर sizes इसे ले सकते हैं।

Pouches made on folded film: linking the pouch style to the fold

Folded film पर बने pouch: pouch style को fold से जोड़ना

Most pouch formulas already give the open web. Side sealing, for example: open = 2H + 2 × Bottom Gazzet + Flap + 2 × HD. When the route folds that web, the style says two things in its Fold box:

ज़्यादातर pouch formula पहले से open web देते हैं। जैसे side sealing: open = 2H + 2 × Bottom Gazzet + Flap + 2 × HD। जब route इस web को मोड़ता है, तो style के Fold box में दो बातें लिखी होती हैं:

  • The width formula gives = The open web before the fold. The open width, the rolls picked before the fold and the kg targets stay exactly what the formula says. The width formula gives = The open web before the fold। Open width, fold से पहले चुने roll और kg target बिल्कुल formula जितने ही रहते हैं।
  • Flap comes from = Each size's "Flap" field. Every size keeps its own flap, so the folded width is the two walls: (open − flap − seal − trim) / 2. Flap comes from = Each size's "Flap" field। हर size का अपना flap रहता है, तो folded width दोनों दीवारें है: (open − flap − seal − trim) / 2।

Setting up a new folding route (admins)

नया folding route सेट करना (admin के लिए)

  1. Process Master. Create or open the folding process and set: Input Roll → Output Roll; Roll behaviour Modify existing roll; Allowed input forms Open web only; Allowed output forms Open web, Folded web, Lay-flat tube; Output form "Sales / stock target decides". A process with these settings is a fold step. Fold and Sheet Seal are set like this.

    Process Master. Folding process बनाएँ या खोलें और सेट करें: Input Roll → Output Roll; Roll behaviour Modify existing roll; Allowed input forms सिर्फ़ Open web; Allowed output forms Open web, Folded web, Lay-flat tube; Output form "Sales / stock target decides"। इन settings वाला process fold step है। Fold और Sheet Seal ऐसे ही सेट हैं।

  2. Work centre. Link the folding machine's work centre to the process, so fold jobs reach that queue and terminal.

    Work centre. Folding मशीन के work centre को process से जोड़ें, ताकि fold job उसी queue और terminal पर आए।

  3. Route template. Put the fold step where it really happens (before printing if you print on folded film). Steps before it run open web; steps after it run the folded or tube roll. If a later step takes tubes only (gusseting, bottom sealing), the route makes a tube.

    Route template. Fold step वहीं रखें जहाँ असल में होता है (folded film पर print हो तो print से पहले)। उससे पहले के step open web चलाते हैं; बाद के step folded या tube roll। अगर बाद का कोई step सिर्फ़ tube लेता है (gusseting, bottom sealing), तो route tube बनाता है।

  4. Product. Roll sizes pick a roll style. Pouch sizes pick a pouch style made for the fold: its Fold box says the formula gives the open web, and where the flap comes from.

    Product. Roll size roll style चुनते हैं। Pouch size fold के लिए बना pouch style चुनते हैं: उसके Fold box में लिखा हो कि formula open web देता है, और flap कहाँ से आता है।

  5. Check. Open a job at the fold step on the work-centre screen: Step stock contract shows "Makes Folded … from … mm open web". The step before shows Open; the step after shows Folded.

    जाँच. Work-centre screen पर fold step का job खोलें: Step stock contract में "Makes Folded … from … mm open web" दिखेगा। पहले वाला step Open दिखाता है; बाद वाला Folded।

Nothing here needs code: new folds, routes, machines and products are all set up on these screens. Only a brand-new kind of roll shape (for example a gusseted tube) needs a new rule from the developers.

इसमें code की ज़रूरत नहीं: नए fold, route, मशीन और product इन्हीं screens पर सेट होते हैं। सिर्फ़ बिल्कुल नए तरह के roll आकार (जैसे gusseted tube) के लिए developers से नया नियम चाहिए।

Common questions

आम सवाल

  • Do I add a flap on the sales order? क्या sales order में flap भरना है?
    No. The size (or its roll / pouch style) carries it into every order line. नहीं। Size (या उसका roll / pouch style) हर order line में ले जाता है।
  • My old tubing sizes showed as open web. पुराने tubing size open web दिखते थे।
    Fixed: the Roll form picker now sets the real form, and existing sizes were corrected. ठीक हो गया: Roll form picker अब असली form सेट करता है, और पुराने sizes सुधार दिए गए।
  • Can I fold a roll without a job? क्या बिना job के roll fold कर सकते हैं?
    Yes: Stock → Stock conversions, pick Fold open web or Fold and seal into tube, fill Folded width, Flap, Seal, Fold trim, check the preview and post. हाँ: Stock → Stock conversions, Fold open web या Fold and seal into tube चुनें, Folded width, Flap, Seal, Fold trim भरें, preview देखें और post करें।
  • The fold step refuses my roll. Fold step मेरा roll नहीं ले रहा।
    The roll is narrower than 2W + flap + seal + trim. Pick a wider open roll, or check the flap on the size. Roll 2W + flap + seal + trim से संकरा है। चौड़ा open roll लें, या size पर flap जाँचें।
