# Roles and daily work / भूमिकाएँ और रोज़ का काम

## ADMIN — Administrator Guide / Administrator गाइड
Start page: /dashboard/admin
Administrator is responsible for secure, policy-compliant execution in assigned ERP modules.
Administrator की जिम्मेदारी है कि निर्धारित ERP मॉड्यूल में सुरक्षित और नीति-अनुपालन निष्पादन हो।

**Responsibilities / ज़िम्मेदारियाँ**
- Execute role-specific actions only within assigned module boundaries. / केवल निर्धारित मॉड्यूल सीमाओं में भूमिका-विशिष्ट कार्य निष्पादित करें।
- Maintain traceable updates with complete audit notes. / पूर्ण ऑडिट नोट्स के साथ ट्रेस करने योग्य अपडेट बनाए रखें।
- Escalate blockers early using governance-approved escalation paths. / गवर्नेंस-स्वीकृत एस्केलेशन मार्गों से बाधाओं को समय पर बढ़ाएँ।

**Daily checklist / रोज़ की चेकलिस्ट**
- Review landing dashboard alerts and open high-priority queues first. / लैंडिंग डैशबोर्ड अलर्ट देखें और पहले उच्च-प्राथमिकता कतारें खोलें।
- Complete pending approvals/tasks and verify downstream impact. / लंबित अनुमोदन/कार्य पूरे करें और डाउनस्ट्रीम प्रभाव सत्यापित करें।
- Close day with unresolved exception review and handoff notes. / दिन समाप्ति पर अनसुलझे अपवाद और हैंडऑफ नोट्स की समीक्षा करें।

**Core work / मुख्य काम**
- Start from /dashboard/admin, execute primary queue actions, and confirm status transitions. / /dashboard/admin से शुरू करें, प्राथमिक कतार कार्य निष्पादित करें, और स्थिति परिवर्तन पुष्टि करें।
- Use Help decision flow before forcing overrides or exception closures. / ओवरराइड या अपवाद क्लोज़ से पहले Help decision flow का उपयोग करें।

**Who to go to / किससे बात करें**
- Access issue -> System Governance / Role Matrix owner. / एक्सेस समस्या -> System Governance / Role Matrix मालिक।
- Data integrity issue -> Module owner + Admin on-call. / डेटा अखंडता समस्या -> मॉड्यूल मालिक + Admin on-call।
- Q: What should I do if an action is missing? A: Verify active role and governance visibility. Then check Role Matrix assignment.
  - प्र: यदि कोई कार्रवाई नहीं दिख रही हो तो क्या करें? उ: सक्रिय भूमिका और गवर्नेंस दृश्यता जांचें। फिर Role Matrix असाइनमेंट सत्यापित करें।
- Q: When should I use override actions? A: Only with documented reason, approval context, and follow-up audit entry.
  - प्र: ओवरराइड कार्रवाई कब उपयोग करें? उ: केवल दस्तावेज़ित कारण, अनुमोदन संदर्भ और फॉलो-अप ऑडिट एंट्री के साथ।

## WATCHMAN — Watchman Gate Guide / चौकीदार गेट गाइड
Start page: /gate
The watchman logs every vehicle in and out of the assigned gate and checks visitors out when they leave. Visitors record their own entry by scanning the gate QR. Watchman access is limited to the gate terminal.
चौकीदार निर्धारित गेट पर आने-जाने वाले हर वाहन को दर्ज करता है और विज़िटर के जाते समय उन्हें चेक आउट करता है। विज़िटर गेट QR स्कैन करके अपनी एंट्री ख़ुद दर्ज करते हैं। चौकीदार का एक्सेस केवल गेट टर्मिनल तक सीमित है।

**Responsibilities / ज़िम्मेदारियाँ**
- Type the invoice number and vehicle number exactly as on the paper and plate; pick party and items from the lists. / इनवॉइस नंबर और वाहन नंबर काग़ज़ और प्लेट जैसा ही टाइप करें; पार्टी और सामान सूची से चुनें।
- Ask visitors to scan the gate QR; their entry is recorded when they submit. Check every visitor out when they leave. / विज़िटर से गेट QR स्कैन करवाएँ; सबमिट करते ही उनकी एंट्री दर्ज हो जाती है। जाते समय हर विज़िटर को चेक आउट करें।
- Never guess quantities or amounts. Leave amount empty when not on the paper. / मात्रा या राशि का अनुमान न लगाएँ। काग़ज़ पर न हो तो राशि खाली छोड़ें।

**Daily checklist / रोज़ की चेकलिस्ट**
- Open Gate home and confirm the right plant is shown at the top. / Gate home खोलें और ऊपर सही प्लांट दिख रहा है यह जांचें।
- Open Visitors (Inside now) and check out everyone who has left; overdue visitors are listed first. / Visitors (Inside now) खोलें और जो जा चुके हैं उन्हें चेक आउट करें; ओवरड्यू विज़िटर सबसे ऊपर दिखते हैं।
- Before shift end, check out everyone still inside who has left. / शिफ्ट ख़त्म होने से पहले, अंदर दिख रहे जो लोग जा चुके हैं उन्हें चेक आउट करें।

**Core work / मुख्य काम**
- Inward or Outward tile → invoice → vehicle → party → items → Save. Only the 'Saved to gate register' screen means it is saved. / Inward या Outward टाइल → इनवॉइस → वाहन → पार्टी → सामान → Save। केवल 'Saved to gate register' स्क्रीन का मतलब है कि सेव हुआ।
- If the screen says 'Not confirmed yet', tap 'Send same entry again' — it cannot create a duplicate. / यदि 'Not confirmed yet' दिखे तो 'Send same entry again' दबाएँ — इससे डुप्लिकेट नहीं बनेगा।

**Who to go to / किससे बात करें**
- Gate not assigned → owner assigns your plant in User Management. / Gate not assigned → owner User Management में आपका प्लांट असाइन करे।
- Wrong entry saved → tell the owner; only the owner can correct it with a reason. / ग़लत एंट्री सेव हुई → owner को बताएँ; केवल owner कारण के साथ सुधार सकता है।
- Q: Does the watchman admit visitors? A: No. Submitting the QR form records the visitor's entry. The watchman only confirms the exit with Check out.
  - प्र: क्या चौकीदार विज़िटर को अंदर दर्ज करता है? उ: नहीं। QR फ़ॉर्म सबमिट करते ही विज़िटर की एंट्री दर्ज होती है। चौकीदार केवल Check out से बाहर जाने की पुष्टि करता है।

मशीनें चालू रखता है: हर ब्रेकडाउन और प्लान किया काम देखता है, टेक्नीशियन लगाता है और जॉब बंद करता है।

**Responsibilities / ज़िम्मेदारियाँ**
- Assign every open breakdown to a technician. / हर खुला ब्रेकडाउन किसी टेक्नीशियन को दें।
- Keep the planned maintenance schedule up to date. / प्लान किए मेंटेनेंस का शेड्यूल अपडेट रखें।

**Daily checklist / रोज़ की चेकलिस्ट**
- Open Maintenance and clear the open and overdue jobs. / Maintenance खोलें और खुले व देर वाले जॉब निपटाएँ।
- Check machines marked down and when they will be back. / down मशीनें और वे कब चालू होंगी, देखें।

**Core work / मुख्य काम**
- Breakdown → assign → work recorded → close. / ब्रेकडाउन → असाइन → काम दर्ज → बंद।
- Planned jobs from the schedule. / शेड्यूल से प्लान किए जॉब।

**Who to go to / किससे बात करें**
- Parts needed: tell the store; machine plans: tell the planner. / पार्ट्स चाहिए: स्टोर को बताएँ; मशीन प्लान: प्लानर को बताएँ।
