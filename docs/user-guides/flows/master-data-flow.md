# Master Data Change Flow

## Nodes
## 1. Draft change
- HI: ड्राफ्ट परिवर्तन
- Outcomes:
  - Review needed
  - Urgent

## 2. Validate downstream impact
- HI: डाउनस्ट्रीम प्रभाव सत्यापित
- Outcomes:
  - Approve -> Publish and communicate effective date.
  - Reject -> Return with correction checklist.
