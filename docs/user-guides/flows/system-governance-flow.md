# System Governance Flow

## Nodes
## 1. Validate policy scope
- HI: नीति स्कोप सत्यापित करें
- Outcomes:
  - Valid
  - Invalid

## 2. Approve with notes
- HI: नोट्स के साथ अनुमोदन
- Outcomes:
  - Done -> Revalidate role visibility and notify stakeholders.

## 3. Reject with action items
- HI: कार्य बिंदुओं के साथ अस्वीकृत
- Outcomes:
  - Returned -> Return to requester with mandatory fixes.
